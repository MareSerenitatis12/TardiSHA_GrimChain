# Contributing

TardiSHA changes must preserve the complete source route and its typed return offices.

Before proposing a change:

```bash
python validation/validate_release.py --full
```

A contribution must not:

- restore digest-byte or `% 12` parent selection;
- choose a Court before deriving both Goetics;
- reverse the Parliament procession under Mirror Math;
- force D-COMP or Truth by assigning the desired answer;
- skip terminal bytes merely because they resemble a Grimchain;
- merge source Truth with return Truth;
- replace a failed hostile test with a weaker assertion;
- introduce an arbitrary return-lineage ceiling.

New behavior should include a direct test, a hostile counterexample, and an explanation in `docs/HOW_IT_WORKS.md` or the appropriate formal document.
