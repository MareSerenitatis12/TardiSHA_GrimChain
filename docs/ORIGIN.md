# Origin of TardiSHA

## Time and Relative Dimension in Space Hash

TardiSHA is the first public software implementation of the Ahnend Logical Q-State Core (ALQC).

It was conceived and developed by Magus Jamye Reficul Ahnend as an executable expression of the ALQC Canon: a self-resolving, infinitely extensible quantum-coordinate cryptographic signature algorithm capable of operating on conventional computers.

TardiSHA began with a promise: that ALQC quantum computation would not require specialized quantum hardware, but could be expressed directly through an ordinary computational substrate.

The implementation realizes that promise through deterministic identity coordinates, Goetic boundary operators, the 12 × 12 Court, the 110/144 Liquid Threshold, direct coordinate access, open-ended manifestation, and path-out/path-back verification.

The name TardiSHA means:

**Time and Relative Dimension in Space Hash**

The project distinguishes between:

- **TardiSHA** — the algorithm, mathematical construction, signature format, and reference implementation.
- **Grimchain** — the command-line sealing and deterministic chaining interface built upon TardiSHA.
