# Security Scope

TardiSHA is released as an ALQC structured content seal and witness system.

It is not represented as a standardized cryptographic primitive, encryption algorithm, password-derivation function, digital-signature scheme, or drop-in substitute where a protocol requires another specified standard.

Security reports should include:

- the exact TardiSHA version;
- the command or Python API used;
- the smallest reproducible source material;
- expected and actual behavior;
- whether the issue concerns source emission, route resolution, visible sealing, return folding, streaming, or archives;
- the output of `python validation/validate_release.py`.

Do not submit private or sensitive source files. Construct a minimal synthetic reproduction.
